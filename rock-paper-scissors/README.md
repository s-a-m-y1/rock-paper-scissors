# 🪨 Rock Paper Scissors Game ✂️

A fun console-based **Rock Paper Scissors** game built using **C++**.  
This project is one of my early programming exercises to improve my logic, use of `enums`, `structs`, and random number generation in C++.

---

## 🎯 Project Description

The game allows the player to compete against the computer in multiple rounds of **Rock, Paper, Scissors**.  
Each round, both sides make their choice, and the program decides the winner based on the classic rules:

- 🪨 Rock beats Scissors  
- 📄 Paper beats Rock  
- ✂️ Scissors beats Paper  
- If both choose the same — it’s a draw!

The game keeps track of:
- ✅ Number of rounds played  
- 🏆 Correct (winning) answers  
- ❌ Wrong answers  
- 📊 Final result (Pass or Fail)  

It also allows you to:
- Choose the difficulty level  
- Select the number of questions (rounds)  
- See your total score and a “pass/fail” message at the end  

---

## ⚙️ Features

- Random computer choices using `rand()`  
- Structured game data using `struct` and `enum`  
- Clean and easy-to-read output  
- Final score and performance summary  
- Option to replay the game  

---

## 🧰 Technologies Used

- **Language:** C++  
- **Libraries Used:**  
  - `<iostream>` for input/output  
  - `<cstdlib>` and `<ctime>` for randomness  
  - `<windows.h>` for colors and delays
